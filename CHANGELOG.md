# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-05

First public release.

### Added
- Menu bar app showing spend and subscription quota for Cursor, Claude Code,
  OpenCode, Codex and DeepSeek, in English, Portuguese and Spanish.
- DeepSeek spend from DeepSeek Harness session logs, priced at the published
  API rates with peak and off-peak windows.
- Optional daily or monthly budget per tool, a global budget, and alerts at
  80% and 100%.
- Codex quota windows with a forecast of when the limit is reached.
- Combined, fixed and pinned menu bar indicators (up to two tools).
- Collector embedded in the app bundle: no separate install step.
